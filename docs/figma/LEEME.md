# Frames del Figma

Una imagen por frame, con el nombre del frame (por ejemplo `Workout - 03 Workout Details.png`), más la lámina "Sistema de diseño de VORA". Son la referencia del ciclo visual (skill `pantalla`) y del subagente `revisor-visual` para quien no tenga el conector de Figma.

Figma del grupo: `figma.com/design/1nvbbfYNYmKAevuaG28J85`. Ancho de referencia: unos 396 dp (Login, 390). Las exportaciones vienen mezcladas a 1x y 2x: comparar siempre a la misma escala.
